# Tarifas de Transporte Terrestre · Ecuador 2026

Página web de consulta rápida de tarifas de transporte terrestre público de pasajeros en Ecuador, basada en el **Anexo 1** de la **Agencia Nacional de Tránsito (ANT)**.

## ✨ Funcionalidades

- 🔍 Búsqueda **de → hasta** por ciudad, cantón o provincia
- ⇄ Botón para invertir la ruta
- 🔁 Búsqueda en ambas direcciones
- 🎯 Modo de coincidencia exacta
- 💰 Muestra la **tarifa 2026** y la **tarifa preferencial**
- 📊 Resumen estadístico de resultados (tarifa más baja, más alta y promedio)
- 🏷️ Desglose de rutas interprovinciales e intraprovinciales
- 📱 Diseño adaptable a móvil
- 🚀 100 % HTML autocontenido, sin servidor ni dependencias (solo la fuente tipográfica desde Google Fonts)

## 📊 Datos

- **2.221 rutas**
- **25 provincias**
- **1.178 ciudades / sectores**
- Fuente: Anexo 1 · Tarifas de Transporte Terrestre Público de Pasajeros (22/07/2026)
